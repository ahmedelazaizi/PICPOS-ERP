# patch: تفعيل تصغير خط اسم الصنف/السعر في كارت نقطة البيع

**الملف:** `font-size-clamp-fix.diff` — يمسّ `lib/presentation/pos/widgets/product_card.dart` فقط (ملف مشترك أصله UralCash).

## الباج
في `_buildInfo` كان حجم خط الاسم/السعر يُحسب:
`(الإعداد × [1.33 للنص فقط] × scaleFactor).clamp(أرضية, سقف)`
والأرضيات كانت مرتفعة — **13/14** (نص فقط) و**10/12** (مع الصور). مع `scaleFactor`
(`(عرض الكارت/100).clamp(0.6, 1.2)`) الذي يهبط لـ0.6 على الكروت الضيّقة، تخفيض إعداد
`pos_product_name_font_size` / `pos_product_price_font_size` (المدى المسموح 10..24) كان
يصل للأرضية **ويتوقف** — فالمستخدم يصغّر الإعداد ولا يصغر الخط.

## الإصلاح
أرضية موحّدة **8.0** (حدّ أدنى مقروء) لكل الحالات، مع الحفاظ على السقوف كما هي —
فالإعداد الآن يسري حتى أصغر قيمة.

## التطبيق (يعمله صاحب المشروع على UralCash)
```bash
git -C D:/URAL-ERP apply --3way patches-for-uralcash/font-size-clamp-fix.diff
# أو git am لو محوّل لـ format-patch
```

UralCash قد تباعد في هذه الدالة.
