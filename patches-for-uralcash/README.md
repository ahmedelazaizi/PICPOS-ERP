# patches لـ UralCash — إصلاحات محرك من جلسة PicPos ٢٧ يوليو ٢٠٢٦

الملفات دي **مخرجات**، مش كود المشروع. اتولّدت بـ `git format-patch`
عشان إصلاحات المحرك اللي اتعملت في PicPos تنتقل لـ UralCash.

> **القاعدة:** التطبيق بيعمله صاحب المشروع من مجلد UralCash. جلسة PicPos
> **ممنوع** تفتح أو تعدّل `D:\URAL-ERP` — ولا حتى تقرا منه. اقرأ HANDOFF.md
> قسم ١.

## ليه الملفان منفصلان

| الملف | بينتقل إزاي |
|---|---|
| `0001-fix-engine.patch` | **بالحرف.** مفيهوش أي إشارة لثوابت العلامة |
| `0002-fix-engine-brand.patch` | **بعد تعديل سطرين** — بيستخدم `Brand` |

الكوميت التاني بيستخدم `Brand.name` و`Brand.dbPrefix`. طبقة فصل الهويات
اتضافت في PicPos، فلو `lib/core/config/brand.dart` **مش موجود** عند
UralCash لازم تستبدلهم بالقيم الحرفية:

| في الـ patch | البديل عند UralCash |
|---|---|
| `Brand.name` | `'UralCash'` |
| `Brand.dbPrefix` | `'uralcash'` |

ولو `Brand` **موجود** عندهم، الملف بيتطبّق بالحرف زي الأول.

## التطبيق

```bash
# من مجلد UralCash
git am --3way /path/to/0001-fix-engine.patch
```

ولو التاني احتاج تعديل، الأسهل:

```bash
git apply --reject /path/to/0002-fix-engine-brand.patch
# صلّح ملفات .rej، وبعدين
git add -A && git commit
```

## ⚠️ سطر واحد **متنقلوش** لو عندك تركيب ويب

في `0002`، `connection_web.dart` بيغيّر اسم قاعدة بيانات الويب من
`cashier_market` لاسم مشتق من العلامة.

اتعمل في PicPos بقرار صريح لأن **المنتجين ديسكتوب ومسار الويب مش
مستخدم**. لكن تغيير اسم داتابيز على تركيب قايم = **فقد بيانات صامت** —
التركيب بيدوّر على اسم مش موجود ويبدأ بقاعدة فاضية.

فلو فيه أي تركيب ويب عند UralCash، **شيل التعديل ده من الـ patch**.
باقي الكوميت (`error_handler`) مالوش علاقة بده.

## اللي جوّه الـ patches

`0001` — تسعة إصلاحات:

1. النسخ الاحتياطية مش مفلترة باسم الداتابيز — بتكسر ٤ دوال: الاستبقاء
   بيمسح نسخ المنتج التاني، ونسخة منتج بتمنع التاني من نسخة الإقلاع،
   والتصدير والإحصاءات بيشتغلوا على نسخ مش بتاعتهم
2. سباق على اسم النسخة (دقة ثانية + `File.copy` بيرمي لو الهدف موجود +
   نسخة إقلاع متوازية) → النسخة بتفشل والحذف بيتلغي عشوائياً
3. النسخة بتتاخد من غير تفريغ الـ WAL → ناقصة
4. زرار «نسخ احتياطي» بيفشل دايماً (اسم داتابيز قديم مثبَّت)
5. **«استعادة» بتقول «نجحت» وهي بتكتب على ملف التطبيق مبيقراهوش**
6. `getBackupStats()` بينادي نفسه → `StackOverflowError`
7. أصناف «ميزان بالحبة» بتترحّل للميزان كأنها بالوزن — الميزان يطبع
   «كيلو»، **والباركود بياخد بادئة الوزن فالسعر بيتحسب غلط على الكاشير**
8. `MONEXIA Market` مثبَّت كاسم شركة على رأس ٣ تقارير
9. بوابة أدوات المطوّر بتقفل بدل ما تفتح بعد `--reset-dev-password`

`0002` — اتنين:

- وسم اللوج كان `MONEXIA`
- اسم داتابيز الويب مشترك بين المنتجين (اقرأ التحذير فوق)

## بعد التطبيق

الإصلاحات دي متحقَّق منها على PicPos بـ:

```
flutter analyze lib          صفر مشاكل
flutter test                 ٣٢٥١ ناجح · ١٢ متخطّى · ٠ فشل
```

الاختبارات اللي بتغطي إصلاح الميزان وأدوات التصفير **مش في الـ patches**
(في كوميت PicPos، وبتغطي كود مش موجود عندكم). لو عايز تغطية الميزان
عندكم، `test/unit/scale_item_unit_type_test.dart` بينتقل بالحرف —
بيختبر دالة موجودة في `0001`.
