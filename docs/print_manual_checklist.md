## ٣. الطابعةُ الحراريّة 58mm

> **تحذير:** المولِّدُ الاحتياطيُّ (`ThermalReceiptGenerator`) يصلِّب 80mm.
> طباعةُ 58mm تتطلّب استخدامَ قالبٍ 58mm من إعدادات القوالب.
> تأكّد أنّ القالبَ الافتراضيَّ مضبوطٌ على 58mm قبل الاختبار.

| # | الخطوة | النتيجةُ المتوقّعة | ✔/✘ | ملاحظة |
|---|---|---|---|---|
| 1 | اضبط قالبَ 58mm كافتراضيٍّ (الإعدادات → القوالب → 58mm سريع) | القالبُ نشطٌ ومعيَّنٌ كافتراضيّ | ☐ | |
| 2 | اطبع إيصالَ بيع | الإيصالُ يملأ عرضَ الورق (58mm) بلا قطع | ☐ | |
| 3 | تحقّق من النصّ العربيّ على 58mm | الحروفُ متّصلة، لا أحرفَ مفصولة | ☐ | |
| 4 | طباعةُ صنفٍ باسمٍ طويل (> 20 حرف) | الاسمُ يلتفُّ إلى سطرٍ ثانٍ بلا قطع | ☐ | |
