**فالتركيب الحرفي (`git apply`) بيفشل على معظم الرقع.** ده متوقَّع ومش عطل.

## التركيب

```bash
git apply --3way ural-01-fix.patch      # واحدة واحدة، بالترتيب
flutter analyze lib test                 # بعد كل واحدة
```

`--3way` بيدمج بسياق الـblob فبيعدّي على تباعد الهوية. لو ساب علامات تعارض،
حلّها يدوياً — **التعارض هنا شبه دايماً سطر علامة تجارية أو رقم إصدار، لا
منطق**. اقرا رسالة الكوميت الأصلية عشان تعرف نيّة التغيير قبل ما تحلّ.

### حالتان محتاجتان يد

* **03 (فاتورة A4)**: التعارض في سطر `'نظام UralCash ERP'` داخل التذييل.
  المنطق (‏`pw.Page` → `pw.MultiPage` + `header`/`footer` + صف عناوين
  `repeat: true`) بينتقل زي ما هو؛ سيب سطر الهوية بتاعكم.
* **06 (قيود v152)**: **ما تنقلهاش حرفياً.** المطلوب فهرسان فريدان:
  `salary_payments(employee_id, period, type)` و
  `employee_attendance(employee_id, date)` — بنمط `idx_je_autopost_dedup`
  (ثابت SoT + `onCreate` + خطوة هجرة + شفاء ذاتي كل إقلاع). استعمل **رقم
  الإصدار التالي عندكم** لا 152، وحطّ الخطوة في ذيل هجراتكم.
  ⚠️ الفهرسان **غير قاتلين** بقصد: `_safeMigrate` بيرمي، ولو رمى هنا التطبيق
  ما بيقلعش — والفهرس طبقة تحصين مش شرط إقلاع. والحضور بيتنضّف قبل الفهرس
  بينما الرواتب **لأ** (سجل مالي مربوط بسند وقيد؛ حذفه بيخرّب الخزنة).
