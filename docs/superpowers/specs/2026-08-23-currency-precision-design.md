# مواصفةُ دقّةِ العملة — `decimalPlaces` يتبع العملة

> قرارُ المالك 2026-08-23: «نعالج ده كبند مستقل عشان ممكن المستخدم يحتاج
> تنصيب النظام على عملة مختلفة».

## ١) الحالةُ المقيسة

| ما هو | القيمة |
|---|---|
| `AppConstants.decimalPlaces` | **`static const int = 3`** (دقّةُ الدينار) |
| `AppConstants.setCurrency(code)` | يبدّل `currencySymbol`/`symbolAr`/`symbolEn`/`nameAr`/`currencyCode` — و**لا يمسّ الدقّة** |
| `CurrencyInfo` | `code` · `symbolAr` · `nameAr` — **لا حقلَ للدقّة** |
| العملاتُ المدعومة | `jod` · `egp` فقط |
| الاستعمالات | **٧٤٨** موضعاً في `lib/` |
| ملفاتُ اختبارٍ تذكرها | ١٧ |

⇒ تنصيبةٌ بالجنيه المصريّ **تحسب وتعرض بثلاث خانات** — وهو ما رآه المالك:
شرائحُ الخزينة `0.000` والمجموعُ `0.00`.

## ٢) 🔴 ثلاثةُ مصائدَ تُقاس قبل لمسِ سطر

### م-١ `_multiplier` يُحسب مرّةً واحدةً ويثبت للأبد

```dart
static const int _precision = AppConstants.decimalPlaces;
static final double _multiplier = math.pow(10, _precision).toDouble();
```

`static final` في دارت **كسولٌ ويُحسب عند أوّل وصول ثمّ يثبت**. فلو لمس أيُّ
كودٍ `FinancialUtils` قبل `setCurrency` (وهو يقع: `init()` تقرأ القاعدةَ
**بعد** إقلاعٍ كامل) لثبّت المضاعفَ على ٣ وبقيت الحساباتُ بثلاث خاناتٍ رغم
اختيار الجنيه — **صامتةً**.

⇒ الدقّةُ تُقرَأ **ديناميّاً** في كلّ استعمال، ولا تُخزَّن في `static final`.

### م-٢ العملةُ تتبدّل في **زمن التشغيل** لا عند التنصيب فقط

`SystemCurrencyNotifier.setCurrency` مربوطٌ بشاشة الإعدادات
(`general_settings_widgets.dart:176` و`…_picpos.dart:183`). فالمستخدمُ يبدّل
العملةَ والنظامُ يعمل وفيه بياناتٌ.

**والسؤالُ الذي يجب أن يُجاب:** مبلغٌ مخزَّنٌ `12.345` بالدينار، ثمّ تُبدَّل
العملةُ إلى الجنيه (خانتان) — ماذا يصير؟ `round()` تُعيده `12.35`. وقيدٌ
مرحَّلٌ اتّزن بثلاث خاناتٍ قد **يختلّ** إن أُعيد حسابُه بخانتين.

**التوصية:** تبديلُ العملة **يُقفَل بعد أوّل حركةٍ ماليّة** (أو يحذّر تحذيراً
صريحاً لا لبسَ فيه). العملةُ قرارُ تنصيبٍ لا تفضيلُ عرض.

### م-٣ `balanceTolerance` مطلقٌ لا نسبيّ

```dart
static const double balanceTolerance = 0.01;          // مطلق
static int get balanceToleranceMinorUnits => (0.01 * _multiplier).round();
```

عند الدقّة ٣ ⇒ ١٠ وحداتٍ صغرى · وعند ٢ ⇒ **١**. والمطلقُ `0.01` يبقى كما هو،
فالسلوكُ متّسقٌ — **لكن هامشَ التقريب يضيق**: بخانتين تصير الوحدةُ الصغرى
`0.01` نفسَها، أي أنّ فرقاً واحداً في الوحدة الصغرى يستهلك السماحَ كلَّه.
يُقاس على قيودٍ حقيقيّةٍ قبل الطرح.

## ٣) التصميم

1. **`CurrencyInfo.decimals`** — `jod: 3` · `egp: 2`. مصدرٌ واحدٌ للدقّة.
2. **`AppConstants.decimalPlaces`** يصير `static int` (لا `const`) يُضبط في
   `setCurrency` من `info.decimals`.
   ⚠️ ونزعُ `const` **يكسر الترجمةَ في كلّ موضعٍ يعتمد عليها ثابتاً** — وهذا
   **مكسبٌ لا عائق**: المترجمُ يعدّ لنا كلَّ نقطةِ تجميدٍ بدل أن نبحث يدويّاً.
3. **`FinancialUtils`**: `_precision` و`_multiplier` يصيران **getters**
   تُقرأ عند الاستعمال. (م-١)
4. **الافتراضُ يبقى `JOD`/٣** — فسويّةُ الاختبارات لا تتبدّل، والانحرافُ
   يقتصر على تنصيبةٍ اختارت الجنيه.

## ٤) لماذا الخطرُ أقلُّ ممّا يبدو

الاختباراتُ تعمل على الافتراض (`JOD` = ٣) ولا تنادي `setCurrency`. فما دام
الافتراضُ ثابتاً، **٧٤٨ الموضعَ تسلك كما هي اليوم** والسويّةُ تبقى خضراء.
والتبدّلُ يقع فقط حين يختار المستخدمُ الجنيه.

⇒ الحدُّ الأدنى للخطر: **لا تُبدَّل القيمةُ الافتراضية**، ويُختبَر مسارُ
الجنيه باختباراتٍ جديدةٍ تُبدّل العملةَ صراحةً وتُعيدها في `tearDown`.

## ٥) الحرّاسُ المطلوبة

- `CurrencyInfo.decimals` صحيحٌ لكلّ عملة (٣ للدينار · ٢ للجنيه).
- `setCurrency('EGP')` ⇒ `decimalPlaces == 2` **و**`toMinorUnits(12.345) == 1234`
  (‏لا 12345) — يُثبت أنّ المضاعفَ **لم يتجمّد**. وهو الحارسُ الذي يمسك م-١.
- `setCurrency('JOD')` ⇒ يعود ٣ — التبديلُ ذو اتّجاهين.
- `round(12.345)` بالجنيه ⇒ `12.35`، وبالدينار ⇒ `12.345`.
- قيدٌ متّزنٌ بالجنيه يبقى متّزناً (م-٣).
- ⚠️ وكلُّ اختبارٍ يبدّل العملةَ **يعيدها في `tearDown`** — وإلّا سرّبت
  الحالةُ الساكنةُ إلى ملفّاتٍ أخرى وأسقطتها بترتيبٍ عشوائيّ. (نفسُ صنفِ
  تسريبِ أدوارِ PostgreSQL المسجَّل في الذاكرة.)

## ٦) ما لا يدخل هذا البند

- **لا تحويلَ عملات** ولا أسعارَ صرف — هذا ضبطُ دقّةٍ لعملةِ نظامٍ واحدة.
  (‏ثمّة `multi_currency_dao` قائمٌ، وهو موضوعٌ آخرُ لا يُخلَط بهذا.)
- **لا هجرةَ بياناتٍ** للأرصدة القائمة — إن أُقرّ القفلُ في م-٢ فلا حاجة.
