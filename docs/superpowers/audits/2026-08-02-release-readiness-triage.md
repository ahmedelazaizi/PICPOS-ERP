## ✅ مؤكَّد — بيمنع الإقلاع أو بيفسد بيانات

### 1. مايجريشن v132 بيفشل ويقفل التطبيق على أي ترقية من إصدار < 132
`lib/data/database/migrations/epoch_3.dart:1571`

```dart
'ALTER TABLE activity_logs ADD COLUMN global_id TEXT UNIQUE'
```

**probe شغّلته على sqlite3 بتاعة المشروع:**
```
ADD COLUMN UNIQUE               => REJECTED: Cannot add a UNIQUE column
ADD COLUMN + partial UNIQUE IX  => ACCEPTED
```

الجملة متغلّفة بـ`_safeMigrate`، وقايمة الأخطاء المسموح تخطّيها
(`database_migrations.dart:22`) فيها `duplicate column name` و`already exists`
و`no such column` **بس** — مفيهاش `cannot add a unique column` → `rethrow` →
`onUpgrade` بيفشل → drift ما بيفتحش القاعدة → `beforeOpen` عمره ما بيشتغل.

الترقية جوه ترانزاكشن، فبترجع وتعيد المحاولة كل إقلاع = **التطبيق ميت نهائياً**
على التركيبة دي. بيضرب بالظبط التركيبات القديمة اللي الإصدار موجّه ليها.

**الإصلاح:** `ADD COLUMN ... TEXT` + `CREATE UNIQUE INDEX IF NOT EXISTS ...
WHERE global_id IS NOT NULL` (النمط المستعمل صح في v142/v148/v149)، وضيف
`cannot add a unique column` لقايمة `_safeMigrate` كخط دفاع تاني.
**الحجم: صغير (~ساعة + اختبار إعادة تشغيل مايجريشن).**

### 3. `storeFkMapping` بيرمي بدل ما يحدّث — ماب الـFK بيتجمّد على أول قيمة
