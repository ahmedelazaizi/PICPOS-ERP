## ✅ مؤكَّد — بيمنع الإقلاع أو بيفسد بيانات

### 1. مايجريشن v132 بيفشل ويقفل التطبيق على أي ترقية من إصدار < 132
`lib/data/database/migrations/epoch_3.dart:1571`

```dart
'ALTER TABLE activity_logs ADD COLUMN global_id TEXT UNIQUE'
```

**probe شغّلته على sqlite3 بتاعة المشروع:**
```
ADD COLUMN UNIQUE               => REJECTED: Cannot add a UNIQUE column
ADD COLUMN + partial UNIQUE IX  => ACCEPTED
```

الجملة متغلّفة بـ`_safeMigrate`، وقايمة الأخطاء المسموح تخطّيها
(`database_migrations.dart:22`) فيها `duplicate column name` و`already exists`
و`no such column` **بس** — مفيهاش `cannot add a unique column` → `rethrow` →
`onUpgrade` بيفشل → drift ما بيفتحش القاعدة → `beforeOpen` عمره ما بيشتغل.

الترقية جوه ترانزاكشن، فبترجع وتعيد المحاولة كل إقلاع = **التطبيق ميت نهائياً**
على التركيبة دي. بيضرب بالظبط التركيبات القديمة اللي الإصدار موجّه ليها.

**الإصلاح:** `ADD COLUMN ... TEXT` + `CREATE UNIQUE INDEX IF NOT EXISTS ...
WHERE global_id IS NOT NULL` (النمط المستعمل صح في v142/v148/v149)، وضيف
`cannot add a unique column` لقايمة `_safeMigrate` كخط دفاع تاني.
**الحجم: صغير (~ساعة + اختبار إعادة تشغيل مايجريشن).**

### 3. `storeFkMapping` بيرمي بدل ما يحدّث — ماب الـFK بيتجمّد على أول قيمة

(النمط موجود في ٧ cases تانية في نفس الـswitch).
**الحجم: صغير جداً (~١٥ دقيقة + اختبار).**

### 15. التحويل بين الخزائن — صفر idempotency على الطرفين → تحويل فلوس مضاعف
- العميل (`cwi_trading.dart:612`) **مش بيولّد `globalId`** أصلاً.
- السيرفر (`api_data_handler.dart:2561-2650`) — قريت الـhandler كامل: **ولا فحص
  dedup واحد** قبل الترانزاكشن، بينما `postSafeTransaction:2423` و`postExpense:142`
  الاتنين عندهم فحص بالـ`globalId`. التحويل هو الاستثناء الوحيد.

تحويل ١٠,٠٠٠ من الدرج للبنك + رد ضايع → الطابور يعيد → **٢٠,٠٠٠ اتحوّلت**
و٤ سندات بدل ٢.
**الحجم: صغير (~ساعتين — عميل + replay + سيرفر).**

### 16. الطابور بيعلّم عمليات مش متعامَل معاها كـ«اتزامنت»
`offline_sync_worker.dart:1716` — `case 'safes'` بيتعامل مع `close` و
`update` **بشرط `isDefault == true`** بس. أي عملية تانية بتقع على `break` →
`return null` → `markAsSyncSuccess` (`:423`).

اتأكدت إن المُنتِج بيصدرها فعلاً: `cwi_admin.dart:128` (`safes/insert`)،
`:152` (`safes/delete`)، `:140` (`safes/update` بأي payload)، و
`cwi_sync.dart:202` (`product_units/update`).

الـ`default:` بيرمي بصوت عالي (إصلاح سابق موثّق)، لكن **case متطابق بعملية
غير متعامَل معاها بيعدّي بصمت**. أدمِن يغيّر اسم الحساب البنكي offline →
يتشال من الطابور كأنه اتزامن → أول DeltaPull يرجّع الاسم القديم.

**الإصلاح:** `else { throw StateError(...) }` في كل case (زي `sales`/`parties`)،
وحوّل `outbox_unhandled_op_dispatch_test` من فحص نصّي للمصدر لاختبار سلوكي.
**الحجم: صغير (~ساعتين).**
