## ✅ مؤكَّد — بيمنع الإقلاع أو بيفسد بيانات

### 1. مايجريشن v132 بيفشل ويقفل التطبيق على أي ترقية من إصدار < 132
`lib/data/database/migrations/epoch_3.dart:1571`

```dart
'ALTER TABLE activity_logs ADD COLUMN global_id TEXT UNIQUE'
```

**probe شغّلته على sqlite3 بتاعة المشروع:**
```
ADD COLUMN UNIQUE               => REJECTED: Cannot add a UNIQUE column
ADD COLUMN + partial UNIQUE IX  => ACCEPTED
```

الجملة متغلّفة بـ`_safeMigrate`، وقايمة الأخطاء المسموح تخطّيها
(`database_migrations.dart:22`) فيها `duplicate column name` و`already exists`
و`no such column` **بس** — مفيهاش `cannot add a unique column` → `rethrow` →
`onUpgrade` بيفشل → drift ما بيفتحش القاعدة → `beforeOpen` عمره ما بيشتغل.

الترقية جوه ترانزاكشن، فبترجع وتعيد المحاولة كل إقلاع = **التطبيق ميت نهائياً**
على التركيبة دي. بيضرب بالظبط التركيبات القديمة اللي الإصدار موجّه ليها.

**الإصلاح:** `ADD COLUMN ... TEXT` + `CREATE UNIQUE INDEX IF NOT EXISTS ...
WHERE global_id IS NOT NULL` (النمط المستعمل صح في v142/v148/v149)، وضيف
`cannot add a unique column` لقايمة `_safeMigrate` كخط دفاع تاني.
**الحجم: صغير (~ساعة + اختبار إعادة تشغيل مايجريشن).**

### 3. `storeFkMapping` بيرمي بدل ما يحدّث — ماب الـFK بيتجمّد على أول قيمة
`lib/data/database/daos/fk_resolver_dao.dart:22`

كهدف التعارض، والتفرّد الحقيقي في `idx_remote_id_local (table_name, local_id)`.

**probe شغّلته:**

`offline_sync_worker.dart:412` النداء `unawaited` فالاستثناء بيروح للـzone.

**الحجم: صغير جداً (~١٥ دقيقة + اختبار).**

## ⚪ مبلَّغ ولسه ما اتحققتش منه بنفسي

مش معناه إنه غلط — معناه إني ما فتحتش الملف. لو قررت تصلّح أي واحد فيهم،
التحقق أول خطوة.

**تزامن:** فقدان كتابات المرآة الصامت أثناء انقطاع الـHQ (`MirrorOfflineException`
متبلعة) · `sales_invoice_items` بيوصل قبل الهيدر فيترفض بـFK والـwatermark
بيتقدّم · الأوراق التجارية `await` بدل `return` فمفيش mapping لـserverId ·
٧ جداول مالهاش case → dead-letter دائم.

**مخزون:** بيع صنف بـBOM بخصم تلقائي من غير قيد COGS · المرتجع بيرجّع الكمية
بالـWAC الحالي والقيد بالتكلفة المجمّدة · `recalculateProductWAC` عند إلغاء
فاتورة شراء · باتشات FIFO مش متقيّدة بالمخزن.

**قاعدة بيانات:** مسار PG بيفقد UNIQUE/PK/FK · `insertOrIgnore` على PG =
INSERT عادي · `NOT NULL` بلا default في مسار الـheal.

**محاسبة:** `ClosingEntryService` بيمدين `contra_revenue` (كود ميت — مفيش
مستدعي) · قيد فاتورة المشتريات بتاريخ النهارده وقفل الفترة متفحّص على
`DateTime.now()` (`purchase_dao.dart:469`, `:835`) — ده قريت السطور وشكله صح
بس ما تتبعتش الأثر على التقارير.

**جرد:** `finalizeAudit` بيطبّق فرق قديم بدل ما يقرا الرصيد الطازج
(`inventory_dao.dart:1037`) — قريت الكود وشفت إنه بيستعمل `item.difference`
فعلاً، بس ما جربتش السيناريو.
