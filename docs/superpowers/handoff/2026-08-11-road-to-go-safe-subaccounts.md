### الوصفةُ المجرَّبة — نجحت على اثنين، طبّقها على الباقي

الإصلاحُ الصحيح لكلّ اختبارٍ ساقط: **توسيعُ نطاق القياس** إلى مجموع الفرع

```dart
Future<double> cashAccountNet() async {
  final parent = await db.getAccountByCode('111');
  if (parent == null) return 0;
  final children = await (db.select(db.accounts)
        ..where((a) => a.parentId.equals(parent.id)))
      .get();
  var sum = await accountNet(parent.id);
  for (final c in children) { sum += await accountNet(c.id); }
  return sum;
}
```

**بقاءُ القيم المتوقَّعة صحيحةً بعد التوسيع هو الدليلُ على أن المال محفوظٌ
منقولٌ لا مفقود.** فعلتُها في `picpos_safe_ledger_agreement_test` و
`picpos_unshifted_sale_variance_test` فمرّت ٢٠٠ و٢٥٠ وفرقُ الصفر كما هي —
وهما الآن مُرجَعتان مع `015395ba` وستحتاجان الإعادةَ نفسَها.

⚠️ **ولا تعدّل بالجملة.** افحص كلَّ متّهمٍ وحدَه: حارسٌ متشدّدٌ في هذا
